🪔 Shri Radha Govind Satsang Ashram

A simple, responsive website for Shri Radha Govind Satsang Ashram (Radha Krishna Dham), Lagma, Darbhanga, Bihar.

✨ Pages
- 🏠 Home — Ashram introduction and upcoming festivals
- 🛕 Explore — Temple history and Darshan gallery
- 🗓️ Daily Schedule — Seva timings and festival information
- 📝 Visit Form — Temple visit pre-registration
  
🧰 Tech Stack
- HTML5
- CSS3 — responsive layouts and styling
  
🚀 Run Locally
Open index.html in your browser, or use Live Server in VS Code.
